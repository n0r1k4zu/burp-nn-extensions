NN-Extensions 導入マニュアル

NN-Extensionsは、独立して完成した2つのBurp Suite拡張（CSV List Input と SF Aura Helper）を、Burpの Extensions 一覧上では 1つのプラグインとして扱えるようにする薄いローダーです。各拡張の内部ロジックや画面には 一切手を加えていません。このページでは「NN-Extensionsとしてどう導入し、内部で何が起きているか」だけを 説明します。各拡張そのものの使い方は、後述する個別マニュアルを参照してください。

Overview

これは何をするもの？

2つの拡張を、Burp上では1回のロードでまとめて有効化するためのローダーです。

Burp SuiteのJython拡張は、1つの.pyファイルにつき1つのBurpExtenderクラス（＝1つの Extensionsエントリ）という単位でロードされます。CSV List InputとSF Aura Helperはもともと別々に配布・開発された 独立した拡張で、それぞれ単体でロードすると Extensions一覧に2エントリ表示されていました。

NN-Extensionsは、この2つをロジックを1行も変更せずに1回のロード操作でまとめて有効化するための コンポジションルート（nn_extensions.py）です。ロードすると Extensions一覧には NN-Extensions という1エントリだけが表示され、その中に両方の拡張のSuiteタブ （CSV List Input タブと SF Helper タブ）と右クリックメニューが これまで通りすべて追加されます。

対象読者

Burp Suiteの基本操作とJython拡張のロード手順（Extender/Extensions > Add）は分かっている前提で書いています。 各拡張自体の機能・使い方はこのページの範囲外です — 同梱している拡張の節にあるリンク先の 個別マニュアルを参照してください。

Setup

インストール

  1. Jythonを用意する

    jython-standalone.jar（バージョン 2.7.x 推奨）をダウンロードしておきます。両拡張とも Jython/Python 2向けに書かれているため、この環境設定は1回で両方に効きます。

  2. Python Environmentを設定する

    Burp Suiteの Extender/Extensions > Options > Python Environment で、そのjarファイルを指定します。

  3. nn_extensions.py を選んでロードする

    Extender/Extensions > Extensions > Add で Extension typeを Python にし、リポジトリ直下の nn_extensions.py を選択します。

    burp-list-input/ と burp-sf-aura/ フォルダは、nn_extensions.py と 同じ場所（リポジトリのルート直下）に置いたままにしてください。nn_extensions.pyは この2フォルダを実行時にimportするため、単体では動作しません。

  4. 読み込み結果を確認する

    成功すると Extensions一覧に NN-Extensions の1エントリと、Burpのメインウィンドウに MyTools タブが追加されます。SF Helperは既定で非表示です。

    NN-Extensions loaded: MyTools (SF Helper hidden; set ENABLE_SF_HELPER = True in nn_extensions.py to show it).
読み込みエラーが出たら

Extender/Extensions > Extensions > NN-Extensions > Errors タブにスタックトレースが出ます。多くの場合、burp-list-input/ または burp-sf-aura/ フォルダが nn_extensions.py と同じ階層に無い（配置がずれている）ことが 原因です。それぞれの拡張自体のエラーであれば、個別マニュアルのトラブルシューティング節も あわせて確認してください。

Bundled tools

同梱している拡張

それぞれ独立して開発・完成している拡張です。詳細は個別のREADME・マニュアルを参照してください。

CSV List Input

Suiteタブ: CSV List Input

Repeaterで送るリクエストの複数項目（URL/Cookie/ヘッダー/JSON・XML本文中の値。入れ子構造も再帰的に展開）に、 CSVで用意したテストデータを送信のたびに自動で差し込みます。Session Handling Ruleのマクロ経由の送信にも対応。 armした対象とは無関係に動く Match & Replace、エンコードされた値の中身だけを書き換える Target & Replace with Decode & Encode、選択した文字列を複数形式で一気にデコードできる Decode 機能も持ちます。

README.md 利用マニュアル

SF Aura Helper

Suiteタブ: SF Helper

Salesforce(Aura/Experience Cloud) 診断を、Burpの HTTP history上で直接支援します。パケットへの採番、 繰り返し通信のAura集約判別（オンデマンドの予約色適用）、CSVワードリストによるリクエスト/レスポンス照合、 そして Google/Mandiant aura-inspector 相当の Aura診断（能動送信・要認可） （オブジェクト列挙・件数取得・実データ抽出など）を提供します。

単体でのロードも可能

各拡張は従来通り、burp-list-input/csv_list_input.py または burp-sf-aura/sf_aura_burp_helper.py を直接選んで単体ロードすることもできます。その場合は Extensions一覧に個別の名前（CSV List Input / SF Aura Helper）で2エントリ表示されます。

How it works

なぜ1エントリで2つ動くのか

ロジックの統合は一切していません。同じcallbacksを2回渡しているだけです。

Burpが実際に直接ロードするのは nn_extensions.py 1ファイルだけです。この中の BurpExtender.registerExtenderCallbacks() は、次の3ステップだけを行います。

  1. burp-list-input/ と burp-sf-aura/ を sys.path に追加する
  2. csv_list_input.py と sf_aura_burp_helper.py を通常のPythonモジュールとして import し、それぞれの（既存の）BurpExtenderクラスをインスタンス化する
  3. Burpから渡された同じ callbacks オブジェクトを、2つのインスタンスそれぞれの registerExtenderCallbacks(callbacks) に渡して呼び出す
# nn_extensions.py（抜粋） import csv_list_input self.csv_list_input_extender = csv_list_input.BurpExtender() self.csv_list_input_extender.registerExtenderCallbacks(callbacks) import sf_aura_burp_helper self.sf_aura_extender = sf_aura_burp_helper.BurpExtender() self.sf_aura_extender.registerExtenderCallbacks(callbacks) callbacks.setExtensionName("NN-Extensions") # 最後に表示名を確定

Burpの callbacks は addSuiteTab・registerContextMenuFactory・ registerHttpListener などを複数回呼べる作りになっているため、この方法で両拡張の初期化処理が そのまま独立して動きます。両拡張はそれぞれ自分自身の callbacks.setExtensionName(...) を呼びますが（"CSV List Input" / "SF Aura Helper"）、 nn_extensions.py 側が最後にもう一度 "NN-Extensions" を呼ぶことで、Extensions一覧上の 表示名だけを上書きしています。それ以外、両拡張のコードは1バイトも変更していません。

拡張のアンロード

CSV List Inputは自分自身で IExtensionStateListener を登録しており（arm解除などの後始末を行う）、 これはCSV List Input側のインスタンス自身に対して行われるため、NN-Extensions経由でロードした場合でも そのまま同じように機能します。SF Aura Helperはそもそも状態リスナーを持たないため、対応不要です。

Troubleshooting

トラブルシューティング

Extensions一覧に2エントリ出てしまう

nn_extensions.pyではなく、csv_list_input.pyとsf_aura_burp_helper.pyを それぞれ個別にAddしてしまっている場合にこうなります。一度両方をRemoveし、nn_extensions.pyだけを Addし直してください。

片方のタブしか出てこない

Extender/Extensions > NN-Extensions > Errors タブを 確認してください。多くの場合、burp-list-input/またはburp-sf-aura/フォルダの中身が 移動・欠落しているか、nn_extensions.pyと同じ階層に無いことが原因です。

拡張を編集したのに変更が反映されない（Reload extension）

CSV List Input側（csvlistinput/パッケージ）は、Burpの「Reload extension」でも sys.modulesキャッシュとJythonの$py.classバイトコードキャッシュを自前で パージするようになっているため、通常はそのまま反映されます。反映されない場合は、一度Extensions一覧から NN-Extensions自体をRemoveしてから再度Addしてください。

片方の拡張だけを使いたい

同梱している拡張の節にある通り、各拡張はburp-list-input/csv_list_input.py またはburp-sf-aura/sf_aura_burp_helper.pyを直接選んで単体ロードすることもできます。 NN-Extensionsはあくまで両方をまとめて使いたい場合のローダーです。

Reference

用語集

コンポジションルート
他のモジュールを組み合わせて配線するだけの、最上位の薄いエントリポイント。nn_extensions.py自体は独自のロジックを持たない。
callbacks
BurpがregisterExtenderCallbacks()に渡すオブジェクト。タブ追加・リスナー登録・拡張名設定などのAPIをまとめて持ち、複数の呼び出し元から共有して使える。
Suiteタブ
callbacks.addSuiteTab()で追加される、Burpメインウィンドウ上部のタブ。1つの拡張から複数追加することも、複数の拡張が別々に追加することもできる。
NN-Extensions — CSV List Input と SF Aura Helper を1つのBurp拡張として読み込むためのローダー。
